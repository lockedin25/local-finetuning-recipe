# Fictional examples

Alex and Sam are fictional participants. These short messages were written for this recipe and do not reproduce or paraphrase a private conversation. The email uses the reserved example.com domain.

Run the parser and redactor with `uv run python tools/recipe.py demo --workspace /path/outside/repository/demo`. Use a new directory: the demo refuses to overwrite an existing chat export.

Model-generated demonstrations are excluded even when their prompts are fictional. A private fine-tune can produce private information from a fictional prompt.
